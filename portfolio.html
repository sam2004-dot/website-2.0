project 1

Dit project is een noodlamp op basis van een LDR (lichtgevoelige weerstand). De lamp gaat automatisch aan wanneer het omgevingslicht donker genoeg is, en uit wanneer er voldoende licht is.

Componenten: LDR, potentiometer, LED, weerstanden, transistor, breadboard.

Wat ik heb geleerd: Hoe een LDR werkt in combinatie met een potentiometer om de gevoeligheid in te stellen, en hoe je een transistor gebruikt als schakelaar om een LED aan te sturen.

project 2

Dit project is een motorsimulatie in Wokwi als voorbereiding op de zelfrijdende auto. Via een simulatie heb ik een motor nagebootst met behulp van LEDs om de werking te testen voor ik het in het echt bouwde.

Componenten: Wokwi simulator, motor, LEDs, weerstanden.

Wat ik heb geleerd: Hoe je een motorsturing simuleert en hoe LEDs gebruikt kunnen worden om de richting en snelheid van een motor visueel weer te geven.

project 3

Dit project is het begin van de zelfrijdende auto. In plaats van sensoren te gebruiken, hebben we eerst met drukknoppen gewerkt om de motoren te testen en de basiswerking van de auto te begrijpen.

Componenten: Drukknoppen, motoren, Arduino, breadboard, weerstanden.

Wat ik heb geleerd: Hoe je motoren aanstuurt via drukknoppen en hoe je stap voor stap een project opbouwt door eerst eenvoudige invoer te gebruiken voor je overschakelt op sensoren.

project 4

Dit project is een verkeerslicht op een breadbord. De LEDs gaan één voor één aan in de juiste volgorde, net zoals een echt verkeerslicht.

Componenten: LEDs (rood, oranje, groen), weerstanden, breadboard, Arduino.

Wat ik heb geleerd: Hoe je meerdere LEDs aanstuurt in een vaste volgorde met behulp van code en hoe je timing instelt tussen de verschillende lichtstanden.

Project 5

Dit project is een DC naar AC converter gebouwd met een brugschakeling van diodes, ook wel een Wheatstone brug genoemd. Deze schakeling zet gelijkstroom om naar wisselstroom.

Componenten: Diodes, condensator, weerstanden, breadboard, voeding.

Wat ik heb geleerd: Hoe een brugsgelijkrichter werkt en hoe diodes gebruikt worden om de stroomrichting te sturen bij het omzetten van DC naar AC.

Project 6

Dit project is een schematische tekening van een smart home schakeling, gemaakt tijdens het smart home project. De schakeling toont hoe verschillende componenten met elkaar verbonden zijn via een Loxone Miniserver.

Componenten: Loxone Miniserver Gen-2, 24V DC voeding, Loxone Touch Tree, LED Spot RGBW Tree, aanwezigheidsmelder.

Wat ik heb geleerd: Hoe je een professionele schakelingschets maakt en hoe een smart home systeem opgebouwd is met een centrale controller die verschillende apparaten aanstuurt.
