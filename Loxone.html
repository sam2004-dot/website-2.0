Project 6 — Smart Home

Schematische tekening van een smart home schakeling met Loxone Miniserver.

Beschrijving

Dit project is een schematische tekening van een smart home schakeling, gemaakt tijdens het smart home project. De schakeling toont hoe verschillende componenten met elkaar verbonden zijn via een Loxone Miniserver Gen-2. De Miniserver fungeert als centrale controller die de Touch Tree, LED spots en aanwezigheidsmelder aanstuurt via een Tree-bus.

Componenten

  • Loxone Miniserver Gen-2
  • 24V DC voeding
  • Loxone Touch Tree
  • LED Spot RGBW Tree
  • Aanwezigheidsmelder Tree

Wat heb ik geleerd bij dit project

Hoe je een professionele schakelingschets maakt en hoe een smart home systeem opgebouwd is met een centrale controller die verschillende apparaten aanstuurt via een Tree-bus systeem.
